# Product

## Register

product

## Users

Two groups use the Puzzle Icon Playground:

- Engineers choosing icons for AI agents, apps or user avatars. They type or randomize seeds, compare results across sizes, adjust a few options, then copy the component or the configuration into code.
- Designers setting house presets. They choose a colour set and a look that hold up from 24 px to 128 px in a list, then hand the values to engineers.

Both work at a desk, often next to a code editor, and move back and forth between the preview and the controls many times in one session.

## Product Purpose

The playground shows what the generator can produce and makes it fast to find and tune a specific icon. Success means a user reaches an icon they like, sees it at every target size and in a list, and leaves with a configuration they can reproduce from the seed.

## Brand Personality

Precise, calm, crafted. The tool chrome stays quiet so the icons carry the color. Controls read exactly, labels say what they change, and nothing on the page competes with the preview.

## Anti-references

- Generic SaaS dashboards: card grids, gradient headers, hero metrics, decorative stat tiles.
- Dribbble-style glassmorphism: frosted panels, glows and blurred backdrops used as decoration.

## Design Principles

1. The icon is the hero. Every control, color and surface steps back from the preview.
2. Show the real output. Previews use the same component that ships, at the sizes people ship.
3. Exact controls. Every value is visible, labeled with what it changes, and easy to set precisely.
4. Calm density. Many parameters fit on one screen, grouped clearly, without crowding or shouting.
5. Reproducible by default. Seeds and configurations are always easy to see, copy and restore.

## Accessibility & Inclusion

WCAG 2.2 AA: text contrast of at least 4.5:1 (3:1 for large text), visible focus on every control, and every control usable from the keyboard. Motion respects `prefers-reduced-motion`.
